The Next Four

Pygame, Defold, Love2D, and MonoGame. Four more engines. Four more resume lines.

🐍
Pygame

Python game library. Sprites, sound, physics — all in Python you already know. Closest thing to "game dev with no new language."

Python Easy
🔷
Defold

Free, lightweight 2D engine from King (Candy Crush studio). Uses Lua. Same bracket as Solar2D — one Lua skill covers both.

Lua Medium
💚
Love2D

Minimal Lua framework beloved by indie devs. No editor — pure code. A small platformer or shooter covers the Cocos2d-x bracket.

Lua Easy
🎯
MonoGame

The engine behind Stardew Valley and Celeste. C# / .NET — pairs with your Stride work. A sprite renderer covers the bracket.

C# Medium

Get Running

Pygame installs in seconds. Love2D is a single executable. Start there.

~/PixelForge $ pip install pygame-ce
Successfully installed pygame-ce-2.x

~/PixelForge $ python demos/pygame/asteroid_field.py
★ Pygame window opened — asteroid field running

~/PixelForge $ love demos/love2d/
★ Love2D window opened — neon breakout running

~/PixelForge $ python launcher.py
★ PixelForge launcher started

~/PixelForge $
